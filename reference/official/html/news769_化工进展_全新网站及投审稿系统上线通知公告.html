    关于《化工进展》全新网站、投审稿系统上线的通知公告

     

    尊敬的各位作者、读者及专家：

    为进一步提升服务品质与用户体验，向广大用户提供更优质、高效的服务，《化工进展》期刊搭建了全新的投审稿系统及网站，将于2025年12月30日正式上线运行。新平台在功能、内容与用户体验上均实现了全面革新，具体功能信息及新旧网站、投审稿系统更替事项通知如下：

    一、新网站功能

    《化工进展》唯一官网网址：https://www.hgjz.com.cn

    1. 全新投稿界面友好便捷，系统具备智能解析功能，可自动提取上传文档中的文章题目、摘要、作者信息等，有效减少作者重复录入工作，提升投稿效率。

    2. 新增短信验证码登录端口。作者、审稿专家可通过手机号及验证码登录系统。

    3. 关联“学术先知”微信公众号后，可通过微信了解稿件处理进展。

    4. 采用全新视觉设计与人性化交互，页面更简洁，导航更清晰。

    二、新网站更新注意事项

    1. 旧系统中的注册用户信息已导入新系统，无需重新注册。首次登录可通过 “账号 + 密码”、“手机号 + 短信验证码”进入系统。登录后可修改密码及个人信息，之后即可通过“手机号/邮箱/账号 + 密码”，以及“手机号 + 短信验证码”登录。

    2. 自2025年12月30日起，旧系统注册及投稿功能将关闭，不再接收任何新投稿件，直至旧系统内已有稿件处理完毕后关停。2025年12月30日前已在旧网站提交的稿件，审稿及出版流程仍在旧网站及系统进行，直至稿件出版。该期间，作者、专家可使用原账号和密码，登录“旧作者登录入口”“旧专家审稿入口”“旧编委终审入口”，查阅过往发布的历史信息，处理未完成的稿件及备份数据。

    3. 新网站建议使用Chrome、Firefox、Edge、360极速版等主流浏览器的最新版本访问，以获得最佳体验。

    4. 在新旧系统过渡期间，如果您遇到任何问题或需要帮助，请与编辑部联系。

     

    唯一官网：https://www.hgjz.com.cn

    联系电话：010-64519500

    E-mail：hgjz@cip.com.cn

     

    由此给您带来的不便，敬请谅解。
