# 《化工进展》参考文献著录规则摘要（2024）

来源文件：`reference/official/hgjz_reference_format_2024.docx`。

## 总体规则

- “参考文献”标题：5 号黑体，居中，不排序号。
- 参考文献内容：小 5 号宋体；外文和数字用 Times New Roman。
- 每条左起顶格排；序号用阿拉伯数字，加半角方括号；序号后空一字格接内容。
- 文献必须按正文引用先后顺序列出。
- 附录中出现的参考文献引用与正文使用同一套编号，纳入全文首次引用顺序。
- 著录项目按 GB/T 7714—2015 和《化工进展》具体要求填写。
- 文献各要素必须齐全，并按原文献发表语种填写。
- 中文文献采用先著录中文、再著录英文的形式；英文若原文献给出，不得自行翻译。
- 必须给出文献类型标识代码，如 `[J]`、`[M]`、`[P]`、`[S]`、`[C]` 等。
- 三名及三名以内作者全部列出；三名以上列前三名后加 `, 等` 或 `, et al`。
- 外文作者姓在前，姓全部大写；名首字母大写，其余小写；本刊要求尽量使用全名，不使用缩写。
- 外文期刊名用正体，推荐使用全名。
- 每条文献末尾加半角句点 `.`。
- 日期格式：`YYYY-MM-DD`。
- 著录符号使用英文半角符号。

## 文献类型代码

- 普通图书：`[M]`
- 会议录：`[C]`
- 汇编：`[G]`
- 报纸：`[N]`
- 期刊：`[J]`
- 学位论文：`[D]`
- 报告：`[R]`
- 标准：`[S]`
- 专利：`[P]`
- 数据库：`[DB]`
- 计算机程序：`[CP]`
- 电子公告：`[EB]`
- 档案：`[A]`
- 舆图：`[CM]`
- 数据集：`[DS]`
- 其他：`[Z]`

## 结构化生成格式

- 期刊：`作者. 文章标题[J]. 刊名, 出版年, 卷(期): 页码.`
- 图书：`主要责任者. 题名[M]. 版次. 出版地: 出版者, 出版年: 页码.`
- 会议论文：`作者. 文章标题[C]//论文集或会议名称. 出版地: 出版者, 出版年: 页码.`
- 专利：`专利申请者. 专利题名: 专利公开号[P]. 公告日期或公开日期.`
- 标准：`主要责任者. 标准题名: 标准号[S]. 出版地: 出版者, 出版年.`
- 学位论文：`作者. 论文题目[D]. 出版地: 出版者, 出版年.`
- 科技报告：`作者. 题目[R]. 出版地: 出版者, 出版年: 页码.`
- 报纸：`作者. 题目[N]. 报纸名称, 年-月-日(版面).`
- 电子文献：`主要责任者. 题名[EB/OL]. (出版日期) [引用日期]. 获取和访问路径.`

## 工具链实现状态

- 生成器支持结构化生成：`J`、`M`、`C`、`P`、`S`、`D`、`R`、`N`、`EB/OL`。
- 生成器支持中文条目的英文对应行：`text_en` / `translated_text` / `english_text`。
- 检查器检查正文和附录引用是否为上标、文后编号是否连续、序号后是否空一字格、是否有文献类型标识、是否半角句点结尾、是否存在全角著录标点、中文文献是否疑似缺英文对应行。
